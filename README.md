# 🏡 Stu-Nest (Front-End)

> A centralized web platform designed to simplify finding student boarding accommodations near Sri Lankan universities.

---

## 📌 Overview

**Stu-Nest** bridges the gap between Sri Lankan university students and local boarding owners. Instead of relying on roadside banners or scattered social media posts, Stu-Nest offers a streamlined, transparent platform where students can search, filter, and review verified accommodations near their campus.

> **Note:** This repository currently contains the **front-end client** application only. 

---

## ✨ Key Features (UI / Front-End)

- 🔍 **Campus-Centric Search:** Search listings by university and distance radius.
- 🏷️ **Smart Filters:** Filter by budget (LKR), room type (single/shared), attached bathrooms, meal options, and gender preference.
- 📱 **Mobile-Responsive Design:** Fully optimized for seamless mobile and desktop browsing.
- 📋 **Property Detail Views:** Clear photo carousels, key amenities, and student review displays.
- 🔐 **Auth Interfaces:** Dedicated login and registration screens for students and property owners.
- 📊 **Owner Dashboard:** Intuitive UI for listing management and viewing inquiries.
